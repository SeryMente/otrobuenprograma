Cómo se construye este recorrido

Importa un JSON de Whisper con words y segments, cada elemento con start y end. Elige la sección que acompaña a cada fragmento. Las palabras permiten saltar al instante correspondiente. El seguimiento se pausa cuando navegas manualmente.

No hay una transcripción ficticia ni conexión automática a Groq. La llave se incorporará por una vía segura, nunca al código público. Este prototipo no modifica el sitio principal ni el libro de cuentas.

Las secciones conservan contenido de la página actual como material de trabajo, no como guion aprobado. Las asignaciones de audio se exportan; no se envían automáticamente. Consultar cuentas claras.
